# sql_analysis-on-diabetes-data
SQL &amp; statistical analysis of 130-US-hospitals diabetes encounters. 
In a large real-world hospital-encounter dataset for diabetic patients: (1) what do medication and dosage-adjustment patterns look like for readmitted patients, and does that differ by how soon they're readmitted; (2) do demographic factors (gender, age, race), lab results (glucose, HbA1c), or weight meaningfully associate with readmission or dosing; and (3), where an association is found, is it large enough to matter clinically, or just large enough to be statistically detectable in a sample this size? The third question turns out to be the most important one this analysis answers.
